## DeepSeek 真实 API 联调（会产生费用）

`_01_data/test_data_50.csv` 包含 50 条独立生成的虚构房源，所有小区、编号、房源属性及租金均为人工构造的测试值，未使用原始 Excel 或真实房源。租金列仅为测试结果表占位标签，不能用作真实预测准确性评价。

运行 `python _05_tests/_04_generate_test_results.py`，使用本地 `.env` 的 DeepSeek 配置，每条独立 Zero-shot 请求，首次最多 50 次请求，不自动重试。成功结果写入 `_05_tests/test_result/Beijing/0_shot.xlsx`，其他模型列空白。重复运行仅处理尚未成功的房源。虚构租金仅用于结果表，不发送给模型。联调结果不得纳入正式实验。

联调结果表额外保存完整 `提示词` 列，用于人工核查；正式实验默认列结构不变。

## 结果目录说明

运行 `_05_tests/_04_generate_test_results.py` 后，结果保存至 `Beijing/0_shot.xlsx`。仅用于联调，不纳入正式实验或准确性评价。Excel 中的真实租金列实际为虚构测试标签，以保留正式输出结构。各城市目录下直接保存各 shot 的 Excel；few-shot 使用 `random_5_shot.xlsx`、`similarity_5_shot.xlsx` 等文件名区分策略。旧目录不再使用；生成的 Excel 默认不提交 GitHub。

测试表最后一列为 `提示词`，保存每条房源发送给模型的完整文本。已有无提示词列的表自动补列并保留预测；对于已有预测，补入的文本为当前模板重建，单元格批注注明未核验是否与原请求完全一致。已有提示词与当前模板不一致时停止，避免混合实验。

`test_result/` 只保存运行生成的结果表，不存放测试代码或说明文件；首次运行时自动创建。
