# LLM Rental Predict

三城房屋月租金预测：比较不同 LLM 在 zero-shot、random few-shot 和 similarity few-shot 条件下的表现。

## 项目约定

- 直接使用已划分的 Excel 数据，不进行清洗或重新划分；训练集仅用于参考样本选择，验证集用于参数确定，测试集用于最终评价。
- 每个城市、样本选择策略和 shot 数对应一个预测 Excel；0-shot 不区分选择策略。
- 每行对应同一个房源，列为样本 ID、真实租金及各模型预测租金（元/月）。不同模型使用相同的参考样本及顺序。
- 评价和绘图独立于 API 调用；失败记录单独保存，缺失预测不填 0。
- 不提交 API 密钥或未经授权的研究数据；本地将数据放入 `data/`。

## 当前状态

初始项目骨架，尚未实现算法、调用 API 或生成实验结果。
