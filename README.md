# LLM Rental Predict

三城房屋月租金预测：比较不同 LLM 在 zero-shot、random few-shot 和 similarity few-shot 条件下的表现。

## 项目约定

- 直接使用已划分的 Excel 数据，不进行清洗或重新划分；训练集仅用于参考样本选择，验证集用于参数确定，测试集用于最终评价。
- 每个城市、样本选择策略和 shot 数对应一个预测 Excel；0-shot 不区分选择策略。
- 每行对应同一个房源，列为样本 ID、真实租金及各模型预测租金（元/月）。不同模型使用相同的参考样本及顺序。
- 评价和绘图独立于 API 调用；失败记录单独保存，缺失预测不填 0。
- 不提交 API 密钥或未经授权的研究数据；本地将数据放入 `_01_data/`。

## 当前状态

已实现楼层规范及数据读取，其他实验模块仍为骨架。尚未调用 API 或生成实验结果。

## 编号及运行顺序

- `_01_config.py`：实验配置；`_02_fix_data.py`：生成规范后的数据；`_03_main.py`：统一入口。
- `_01_data/`：原始及规范后的数据；`_02_src/`：按实验流程编号的核心模块；`_03_experiments/`：实验入口；`_04_results/`：输出；`_05_tests/`：测试；`_06_notebooks/`：探索。
- 先运行 `python _02_fix_data.py`，再读取数据。导入示例：`from _02_src._01_data_loader import load_data`。
- 编号前的下划线用于保证 Python 模块名合法。原始 Excel 随仓库保留，生成的规范版数据默认忽略。
